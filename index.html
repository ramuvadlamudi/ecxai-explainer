    How the formulas work

    Definitions

    Benign share b(x) is the share of normal-activity values at least as suspicious as the alert's value. An item is benign-common when b ≥ 0.10. Weight w = 1 − b. The explanation shows the top-k items by weight.

    Relevant components K are the ATT&CK data components that detect the mapped techniques in the target tactic plus the techniques of the shown items. Relevant sources are catalogue sources that provide any component in K.

    • M1 = 1 − mean b over the shown items
    • M2 = attribution on benign-common items ÷ total positive attribution
    • M3 = relevant sources collected (or collected and empty) ÷ relevant sources
    • M4 = components in K that some source provides ÷ |K|; the rest are blind spots
    • M5 = weight of shown items mapped to the target tactic ÷ weight of shown items
    • M6 = valid claims ÷ proposed claims; an absence claim is valid only if its source was collected
    • M7 = overlap of the top-k by weight and the top-k by attribution ÷ k

    Each check has a fixed threshold and a fixed action. No language model, no randomness and no network call is involved, so the same input always gives the same explanation and the same fingerprint.

    Limits

    This is a teaching tool. The worked examples are illustrative inputs, not measured data. The checks test whether an explanation is consistent with the alert record and the data catalogue. They do not test whether the alert is a true attack, and they have not been validated with analysts. The weight here is a simplified environment-calibrated importance (1 − b); the thesis version also uses threat relevance and proximity.
